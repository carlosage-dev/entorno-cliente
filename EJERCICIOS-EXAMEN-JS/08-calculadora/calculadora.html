08 · Calculadora básica (ejercicio 4 del profesor)

Nivel: Alto

Calculadora sin usar eval. Funciones sugeridas (pasa el valor del botón como parámetro; puedes usar this.value en el evento):

  1. numero(n): escribe el dígito o el punto en la pantalla. Si la pantalla está en 0, lo sustituye. Si toca empezar un número nuevo (justo después de pulsar un operador o =), la pantalla se reemplaza. No se permiten dos puntos en el mismo número.
  2. operar(op): guarda el número de la pantalla y el operador (+ - * /). Si ya había una operación pendiente, la resuelve antes (así 2 + 3 * muestra 5).
  3. igual(): resuelve con un switch. Dividir entre 0 muestra Error. Redondea para evitar cosas como 0.30000000000000004. Añade al historial (textarea) la línea 2 + 3 = 5.
  4. borrarTodo() (C): pantalla a 0 y olvida la operación pendiente. borrarUno() (←): borra el último carácter; si se queda vacía, pone 0.
