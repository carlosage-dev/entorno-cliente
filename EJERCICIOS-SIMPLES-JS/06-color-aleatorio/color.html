06 · Color de fondo aleatorio

Nivel: Muy fácil (como fondo aleatorio y cuadrados de colores)
  1. cambiarColor(): genera tres números aleatorios de 0 a 255 (rojo, verde, azul) y pon ese color de fondo a la página con document.body.style.backgroundColor = "rgb(r,g,b)".
  2. Escribe en la caja de texto el color usado, por ejemplo rgb(12,200,45).
  3. colorBlanco(): vuelve a poner el fondo blanco y vacía la caja.
  4. Haz que el fondo cambie también nada más cargar la página (evento onload del body).
